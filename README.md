# Uber Next Act: a driver-app concept

A clickable prototype by Alisha Chaudhari of a future Uber driver app for EV drivers. The car becomes a city sensor, and drivers earn from the data it collects as well as from rides.

## What's inside
- **Home:** today's earnings, battery status, live "city sensing" status and the nearest Flash-Hub charger, on a city map (San Francisco).
- **Data Rewards:** drivers earn for anonymised road data, such as pothole detection and road-surface and route data. Each reward is logged by place.
- **Flash-Hubs:** nearby fast-charging stations with distance, charge time and estimated cost.
- **City Insights:** infrastructure alerts, a breakdown of anomalies across the city, and weekly earnings.
- **Privacy Mode and data guardrails:** one switch pauses all data collection. The driver stays in control.
- **Activity and Account:** earnings history, data-rewards log, charging history and preferences.

A concept prototype on mock data. It is not affiliated with or endorsed by Uber.

**Stack:** React + Vite + TypeScript, Tailwind + shadcn/ui. Built with Lovable.

```bash
npm install
npm run dev
```
